# 🧠 Redes Neurais do Zero (Neural Networks from Scratch)

Módulo focado na implementação e fundamentação matemática de arquiteturas de Deep Learning sem o uso de frameworks de alto nível, utilizando apenas **NumPy**.

## 🧪 Experimentos e Notebooks

- `01_perceptron_e_mlp_numpy.ipynb`: Implementação do Neurônio de Perceptron, funções de ativação (Sigmoide e ReLU), Forward Pass e algoritmo de Backpropagation com Gradiente Descendente.

## 🛠️ Ferramentas Utilizadas

- `numpy`, `matplotlib`, `seaborn`
