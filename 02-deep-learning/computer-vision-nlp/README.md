# 👁️ Visão Computacional e Processamento de Linguagem Natural (NLP)

Módulo dedicado à aplicação de Redes Neurais Convolucionais (CNNs) e Redes Recorrentes (LSTMs) em tarefas de visão e linguagem utilizando **PyTorch**.

## 🧪 Experimentos e Notebooks

- `01_classificacao_cnn_pytorch.ipynb`: Construção e treinamento de uma Rede Convolucional (CNN) simples no PyTorch utilizando o dataset Fashion-MNIST.
- `02_analise_sentimento_lstm_pytorch.ipynb`: Pipeline de NLP com tokenização, **Word Embeddings** (`nn.Embedding`), camada **LSTM** para classificação de sentimentos em texto.

## 🛠️ Ferramentas Utilizadas

- `torch`, `torchvision`, `matplotlib`
