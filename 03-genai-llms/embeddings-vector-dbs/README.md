# 🔢 Embeddings & Bancos de Dados Vetoriais

Módulo sobre representação vetorial de textos (Dense Embeddings), métricas de similaridade e busca semântica em espaço multidimensional.

## 🧪 Experimentos e Notebooks

- `01_embeddings_e_busca_vetorial.ipynb`: Geração de embeddings, cálculo de Similaridade de Cosseno com **NumPy** e mecanismo de busca Top-K por proximidade semântica.

## 🛠️ Ferramentas Utilizadas

- `numpy`, `matplotlib`, `seaborn`
