# 📚 Aplicações RAG (Retrieval-Augmented Generation)

Módulo sobre arquitetura RAG para expansão do conhecimento de LLMs com fontes de dados externas sem necessidade de fine-tuning.

## 🧪 Experimentos e Notebooks

- `01_rag_pipeline_do_zero.ipynb`: Construção de um pipeline RAG completo do zero: Chunking de textos, Indexação, Recuperação Vetorial e Injeção de Contexto no Prompt de Geração.

## 🛠️ Ferramentas Utilizadas

- `python`, `numpy`
