# 🤝 Orquestração e Workflows Multi-Agente

Módulo focado em arquiteturas distribuídas de inteligência artificial, onde múltiplos agentes especializados colaboram através de papéis (roles), compartilhamento de memória e orquestração sequencial/hierárquica.

## 🧪 Experimentos e Notebooks

- `01_multi_agent_orchestration.ipynb`: Implementação de um pipeline cooperativo com três agentes (Pesquisador, Analista de Código e Redator Técnico) processando uma tarefa ponta a ponta.

## 🛠️ Ferramentas Utilizadas

- `python`, `dataclasses`, `json`
