# 📈 Regressão e Classificação

Módulo focado nos fundamentos do aprendizado supervisionado para resolução de problemas de predição categórica (classificação) e contínua (regressão).

## 🧪 Experimentos e Notebooks

- `01_classificacao_iris_baseline.ipynb`: Pipeline de classificação supervisionada (EDA, padronização com `StandardScaler`, Regressão Logística vs. Árvores de Decisão e validação cruzada K-Fold).
- `02_regressao_baseline.ipynb`: Pipeline de regressão para variáveis contínuas no dataset California Housing (`LinearRegression`, `Ridge`, `DecisionTreeRegressor`, métricas MAE, RMSE, $R^2$ e análise visual de resíduos).

## 🛠️ Bibliotecas Utilizadas

- `pandas`, `numpy`, `matplotlib`, `seaborn`
- `scikit-learn`
